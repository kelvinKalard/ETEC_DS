# 💧 Consumo de Água

![Python](https://img.shields.io/badge/Python-3-blue)
![GitHub](https://img.shields.io/badge/GitHub-Repositório-black)
![Água](https://img.shields.io/badge/Consumo-Água-blue)

Projeto desenvolvido em Python para classificar o perfil de consumo de água de um imóvel.

## 🎯 Objetivo

O programa solicita o tipo do imóvel e o consumo mensal de água em metros cúbicos (m³).

Com base nas informações digitadas, o sistema informa se o consumo é:

- Comercial controlado
- Econômico
- Moderado
- Excessivo

## 🐍 Linguagem utilizada

- Python

## ▶️ Como executar

1. Abra o arquivo `app.py`.
2. Execute o programa em Python.
3. Digite o tipo do imóvel: comercial, casa ou apartamento.
4. Digite o consumo mensal de água em m³.
5. O programa exibirá a classificação do consumo.

## 🧠 Conceitos utilizados

- Variáveis
- Entrada de dados
- `if`
- `elif`
- `else`
- Operadores lógicos `and` e `or`
