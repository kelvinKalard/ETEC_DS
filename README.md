# Atividade Agenda 06 - Estrutura de Decisão

Atividade desenvolvida para a disciplina de **Desenvolvimento de Sistemas I** do curso Técnico em Desenvolvimento de Sistemas da ETEC.

## Objetivo

Desenvolver um programa em Python que calcule descontos progressivos de acordo com o valor total de uma compra.

### Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até abaixo de R$ 300,00: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.

## Conceitos utilizados

- Entrada de dados com `input()`
- Conversão de valores com `float()`
- Estruturas condicionais `if`, `elif` e `else`
- Operadores relacionais
- Cálculos com porcentagem
- Saída de dados com `print()`
