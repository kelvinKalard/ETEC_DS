# Monitorização de Níveis de Água

Este projeto consiste numa simulação de um sistema de monitorização para um reservatório de água, desenvolvido em Python. Foi criado como parte de uma atividade académica da disciplina de Desenvolvimento de Sistemas I.

## Funcionalidades
- Simulação automática de 5 níveis de capacidade do reservatório.
- Utilização da biblioteca `colorama` para emitir alertas visuais padronizados com cores no terminal.

## Como executar
1. Certifique-se de que possui o Python instalado na sua máquina.
2. Instale a biblioteca necessária executando o comando no terminal: 
   `pip install colorama`
3. Execute o script principal: 
   `python KelvinLopes_Ag11_DSI_Recup.py`
